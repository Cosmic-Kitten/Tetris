# Tetris

A simple browser-based Tetris game built with HTML, CSS, and JavaScript.

## Run it locally

```bash
cd /workspaces/Tetris
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Controls

- Left / Right: move
- Up: rotate
- Down: soft drop
- Space: hard drop
- P: pause

## Goal

Clear lines by filling rows completely. The faster you clear, the higher your score.
